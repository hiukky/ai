**`ai` is a catalog of plugins for coding agents.** Each plugin is a set of
skills: an engineering standard, git conventions, terminal demos, a dotfiles
workflow. Your agent picks them up when the work matches, in Claude Code,
Codex, OpenCode or Antigravity.

## How it works

- **A plugin is a folder of skills.** Install one and every agent on the
  machine gets it, through [uze](https://uze.sh).
- **Skills fire on their own.** `git:commit` commits when work is done;
  `tui:record` takes over when you ask for a demo.
- **Some wait for you.** A skill that restructures a repository, like
  `openspec:init`, only runs when you call it by name.
