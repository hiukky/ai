## Who calls a skill

| Label | The agent | You |
| --- | --- | --- |
| **model + user** | uses it when the work matches | call it by name |
| **user only** | never triggers it | call it by name |
| **model only** | uses it | nothing to call |

Almost every skill is **model + user**: a skill that waits to be asked is
documentation with extra steps. **User only** is for skills that change a
repository's structure, like `openspec:init`.
